# IMPPAT_QSPR_FRAMEWORK
Blind validation (n=133) followed leakage-free 5-fold CV. Zero-variance filtering and iterative VIF pruning reduced 44 topological descriptors to 9, with stability confirmed by PCA and 1,000-iteration bootstrapping (rank stability=0.973). RF, GB, and XGBoost were evaluated with Y-randomization and applicability domain analysis.
